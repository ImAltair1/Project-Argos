# Project Argos

Still very early WIP - i am using this project as a tool to learn how developing an application works. 

My background is in data science and statistics, so i am very knowledgeable in using Python for those situations, but as soon as i leave that bubble i am very much out of my depth, and since i've had the idea of this project swirling around in my head for a long time i decided to use it for learning. This means it will probably not be a very good and usable application for a long time, but hopefully something comes out of this eventually, if everything goes well.
